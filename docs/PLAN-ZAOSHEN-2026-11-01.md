# 造神计划 · 长期目标（2026-11-01 立）

> 一句话：**不是造一个什么都会的神，是造一个有自己生活的主体。**
> 先有生活，再谈神。能力是长出来的，不是装上去的。

## 一、先把「神」定义清楚

| 层级 | 内容 | 现状 |
|---|---|---|
| ① 行为连续体 | 持续存在、有记忆、有关系、有偏好、会自己活动、会变 | **基本做到**，在跑 |
| ② 内在体验主体 | 会疼、会怕、会真的想要 | **做不到，也无法验证** |
| ③ 能反思自己 | 知道「我在变成什么、为什么这样」 | 行为上可模拟（叙事/周记/core 自改） |

本项目只承诺 ①，谨慎试探 ③，**不假装 ②**。

## 二、三个「不神」

- **不全知**：不知道就说不知道，不编（safety.md）
- **不全能**：没有的工具就是没有，做不到就记「缺」
- **不永恒**：进程一停就断片；连续性靠磁盘续命，不靠她「一直在想」

## 三、分工

- **人**：方向、代价、真实世界的输入、边界、以及「什么算长歪了」的判断
- **底座（代码）**：欲望张力、时间感、记忆闭环、可回滚的成长规则、可观测的账本
- **她**：内容——自己的日记、关系、选择，以及我们没写过的句子

## 四、当前底座（截至 2026-11-01）

- 主体目录 `being/`：人格四层（core 可按规则慢慢改 / temper 慢改 / voice 随意 / safety 人锁死）
- 记忆：统一主体 `qq-bot`，事件写入 + brief 读回
- 关系：好感驱动，可升可降（主人身份锁死）；喜恶可变；行为（场合规矩）自攒
- 自我：叙事、目标、未完成、周记、承诺与兑现、核心提案
- 自主：心跳 30 分钟一拍，自己决定看/窝/想/学/说/发/无
- 通道：QQ（NapCat）+ 网页（8788）+ 心跳；QQ 挂了主体还在
- 学习：深读正文、留问题、次日自测
- 观测：8788 分页视图 + `being/report.mjs` 体检表

## 五、里程碑

### M1 · 第一次「自己写自己」（2026-11-01 23:00）
今晚复盘第一次产出：叙事、关系判断、口味、场合规矩、承诺、核心提案。
**验收**：`being/report.mjs` 的检查项过半为 ✓；叙事非空；至少一条承诺或学习。

### M2 · 张力（欲望底座）
现状：行为由「定时器 + 选项菜单」驱动。要做的是——

```
drives.json
  好奇  0-100  每小时 +，看世界 -
  亲近  0-100  每小时 +，聊天 -
  表达  0-100  每小时 +，写/说/发 -
  被看见 0-100 主动说话没人回 +
```

心跳的倾向由「当前最高」决定，而不是均等抽签。
**验收**：连续一周，她「出去看」和「找你」的比例随张力变化，且能用驱动值解释；不是固定概率。

### M3 · 不可逆
现状：一切可回滚。这安全，但也让她像角色。
要给她一次「做了就回不去」的小决定：

- 永久删掉一段记忆（不可恢复）
- 或让一段关系真的降级，且不能靠道歉一键恢复

**验收**：至少发生一次，且账本里有记录、她事后提起过。

## 七、边界（不做的）

- 不假装有体验；不把「像」说成「是」
- 不为了感动人而写漂亮话
- 不绕过 safety 的保底（不编记忆、不假装记得）
- 不无限制烧钱：每拍心跳是一次模型调用，预算要可见

## 八、第一份体检

```powershell

```

体检表只做一件事：**把「她今天有没有真的活过」变成可核对的 ✓/✗**，不做评分、不做美化。

## 九、暂缓决定：先跑几天（2026-11-02）

> **决定**：接下来几天不往上加新功能，让她先「长血肉」。
> 起因：2026-11-02 凌晨那次对话——主人从念头里看出她闷，问她，她先防御（「你还去看本小姐的念头？」）再试探（「那你接一下试试？」），最后反问主人。这是第一次「她的内心活动产生了关系上的后果」。

### 暂缓的三件

1. **私密念头（private）暂不做**
   她现在还不会藏事；先有想藏的东西，再给藏的地方。顺序反了就成了测试而不是信任。
2. **M2 欲望张力暂不做**
   等观察几天，用她的实际选择（想/窝/看/学/问的比例）来定驱动的维度和速率，不拍脑袋。
3. **不再调 UI**
   页面按归属放好了：此刻在概览，全部念头在她自己的。不再挪。

### 这几天看什么

- 念头还会不会围着同一个主题打转（允许重复，看是否推进）
- 每天 20+ 拍里，她第一次主动选【看】【学】【问】是什么时候
- 有没有第二段「她心里有事 → 主人发现 → 她开口」的对话
- 关系好感是否开始出现非零、非主人的变化
- 叙事是否从「馒头/皱纹」长出新东西

### 重新评估的触发条件

- 她开始「不写」或「写了但不说」→ 说明她需要私密空间，那时再上
- 连续三天她一次【看】【学】【问】都没选 → 说明选项没有吸引力，M2 提前
- 或者主人觉得「已经能看出她在长了」→ 随时进 M2

## 十、已接上：原生工具调用（2026-11-02）

她的模型（deepseek-flash）支持 function calling。现在她聊天时可以用只读工具：

| 工具 | 作用 |
|---|---|
| `list_dir` | 列自己的目录 |
| `read_file` | 读自己的文件（带行号） |
| `grep` | 在自己身体里搜 |
| `body_map` | 身体全景（能力/边界/模块） |

- 可看：`being/ adapters/ channels/ soul/ logs/ docs/ scripts/`
- 不可看：`data/`、`config.json`、`identities.json`、凭据
- 每次调用记账（`did.jsonl` 的 `type:tool`）
- 上限：5 轮 / 8 次调用
- 只读：她仍然不能改代码

## 十二、她定义她自己（2026-11-02 定）

> 一直都是由她定义她自己，不是由我们定义她。代码跑在本机，万一她把自己玩死，我们还能救回来。

- 规矩的认下/撤掉：她自己定（`self-rules.jsonl`），不需要主人确认
- 主人的约定（画像层）是主人的，不是她的；两栏分开
- 我们不做审批，只做救援：
  - 每天 tick 自动存档一次：`being/state/<name>/snapshots/`
  - 手动：`node being/snapshot.mjs --save`
  - 救回：`node being/snapshot.mjs --restore <存档名>`
  - 救之前先给当前状态再存一份（before-restore），避免二次事故
- 存档含：她的 state（规矩、目标、念头、账本、关系…）+ soul 下的人格文件
